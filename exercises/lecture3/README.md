# HTML workbook

Covers lecture GitHub activities: named workbook, GET link, form with six form attributes and multiple controls, embedded video with title and caption, geolocation, drag/drop and localStorage. Geolocation requires user permission and HTTPS or localhost; denial is handled. API references: https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API and https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API.
