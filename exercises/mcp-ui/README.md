# MCP frontend classwork

Based on https://github.com/lucianoayres/mcp-server-node (MIT); upstream license retained. The starter's addition tool and prompt are retained. The API-key-return example is omitted from this browser-facing demonstration.

Run `npm install` then `npm start` in this directory. Open http://127.0.0.1:3011.

Dynamic elements: tool refresh, live tool filter, an addition form calling the actual MCP tool through a Node/stdio bridge, and request history with clear action. The browser does not receive environment secrets. This is a local-only workshop server.
