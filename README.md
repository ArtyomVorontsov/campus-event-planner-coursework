# Campus Event Planner — Web Programming coursework

A separate coursework project and lecture exercises by Voroncovs Artjoms.

## Final application

[`app`](app) contains the Express + SQLite Campus Event Planner. See its README for setup and API routes. It provides event search, categories, sorting, event creation, RSVP capacity checks, a persistent checklist, theme switching, and status feedback. Its stylesheet pipeline uses Sass followed by PostCSS/Autoprefixer.
